# Deercast web app

The Deercast app: https://jjpvoskuil.github.io/Deercast/ (was deercast-john.netlify.app until 2026-11-09) — phone-first React (Vite) + Leaflet.

- **Sign-in & data:** Supabase (Google provider). Who can read/write what is enforced by row-level security in
  `supabase/schema.sql` (re-runnable; paste into Supabase → SQL Editor). Only emails in `app_users` get in.
- **Keys:** `src/config.js` holds only the Supabase URL + *publishable* key (public by design). No secret keys in `web/`.
- **Screens:** Forecast, Map, Hunt Log, Shot & Recovery, More (Grounds, Bow setup, Regulations, Development).
  Shared shell/tab bar `Shell.jsx`; theme tokens `styles.css` (Light by day, Soft from 30 min before sunset to
  30 min after sunrise, manual override).
- **Logic** in `src/lib/` mirrors the Python package and is parity-tested (`npm test`) against fixtures generated by the
  scripts in `supabase/` (make_fixtures, make_model_fixtures, make_static_data, make_shot_fixtures).
- **Weather/terrain/places:** Open-Meteo, zippopotam.us, FCC census, OpenStreetMap Overpass — keyless, from the phone.
- **Hosting:** GitHub Pages via `../.github/workflows/pages.yml` (builds with `BASE=/Deercast/`), auto-deploys on push.
- **Demo:** add `?demo` to the URL (or leave the key unset) to use made-up data stored only in that browser.
- **Import:** `python supabase/make_import.py <deercast-data>/data > deercast_import.sql` — output is private data; never commit.

Dev: `npm i && npm run dev`.
